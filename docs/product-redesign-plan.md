# media-content-insight 产品改版计划

## 1. 改版目标

`media-content-insight` 从「内容洞察 MVP」升级为「多平台赛道机会与合规触达工作台」。

核心目标:

- 用户输入一个赛道或关键词,系统通过官方授权 API 发现相关内容、评论机会和潜在线索。
- AI 只负责生成评论或私信草稿,不直接发送。
- 用户必须逐条审核、修改、确认后,系统才通过官方 API 执行发送。
- 所有发送动作保留额度限制、敏感词检查和审计记录。
- 页面设计改为 Apple 风格:简约、高级、留白充足、色彩舒适,每个页面只完成一个清晰任务。

## 2. 合规边界

本次改版只设计和实现「官方 API + 人工确认」路径。

允许:

- 读取官方 API 授权范围内的平台内容、评论和用户公开信息。
- 根据内容和评论生成 AI 草稿。
- 用户人工确认后,通过官方 API 发送评论或私信。
- 记录发送状态、额度消耗、失败原因和审计日志。

不允许:

- 使用 Cookie、浏览器自动化或模拟点击绕过平台限制。
- 绕过验证码、风控、登录校验或平台权限。
- 未经用户确认自动批量评论或私信。
- 对无授权或无官方 API 权限的平台执行发送动作。

## 3. 核心业务流程

```text
赛道搜索
  -> 发现内容与评论机会
  -> 生成评论/私信草稿
  -> 人工审核与修改
  -> 确认发送
  -> 写入触达记录与审计日志
  -> 沉淀用户线索
  -> 输出赛道报告
```

## 4. 左侧导航结构

第一版只保留 7 个一级入口,不展开复杂二级菜单。

```text
工作台
赛道搜索
机会
草稿审核
线索
报告
平台集成
```

### 4.1 工作台

用途:告诉用户今天最该处理什么。

页面只展示:

- 待审核草稿数量
- 新发现机会数量
- 平台授权状态
- 3 条今日优先事项
- 2 条下一步建议

### 4.2 赛道搜索

用途:输入赛道,开始跨平台发现。

页面只展示:

- 赛道/关键词输入框
- 平台选择:抖音、B 站、小红书、公众号
- 开始分析按钮
- 最近搜索
- 简单搜索设置

### 4.3 机会

用途:展示系统发现的可跟进机会。

页面只展示:

- 当前赛道
- 机会列表
- 平台来源
- 机会类型,例如教程需求、购买意向、求推荐、踩坑反馈
- 查看机会按钮

### 4.4 草稿审核

用途:审核 AI 生成的评论和私信草稿。

页面只展示:

- 评论草稿 / 私信草稿切换
- 3 到 5 条待审核草稿
- 草稿详情
- 修改按钮
- 确认发送按钮
- 敏感词检查和审计提示

### 4.5 线索

用途:管理已经识别出的潜在用户。

页面只展示:

- 单个线索详情
- 来源平台
- 用户意图
- 跟进状态
- 最近互动时间线
- 下一步建议

### 4.6 报告

用途:复盘赛道和触达效果。

页面只展示:

- 赛道趋势摘要
- 高频痛点
- 高转化内容类型
- 触达结果摘要
- AI 报告正文

### 4.7 平台集成

用途:管理官方 API 授权和权限。

页面只展示:

- 平台连接状态
- Token / 授权有效期
- 当前权限
- API 额度和频率限制
- 重新授权入口

## 5. 视觉方向

设计关键词:

- Apple-inspired
- 简约
- 高级
- 舒适色彩
- 大留白
- 单页单任务
- 信息分层清晰

设计约束:

- 左侧导航默认不展开。
- 每个页面只解决一个核心问题。
- 首页不做复杂仪表盘。
- 不使用大面积高饱和渐变。
- 不堆叠卡片,不做卡片套卡片。
- 操作按钮保持克制,主按钮每屏尽量只有一个。
- 状态色只用于必要反馈:绿色表示正常/可发送,琥珀色表示需审核/需修改,红色表示风险/失败。

## 6. 页面改版顺序

### Phase 1: 前端信息架构重构

- 新建 Apple 风格应用壳层。
- 改造左侧导航为 7 个一级入口。
- 移除现有首页的大面积营销式 hero。
- 建立统一页面标题、右侧状态区、主内容区域。

### Phase 2: 核心静态页面落地

- 工作台页面。
- 赛道搜索页面。
- 机会页面。
- 草稿审核页面。
- 线索详情页面。
- 报告页面。
- 平台集成页面。

### Phase 3: API 与数据模型调整

- 增加平台集成模型。
- 增加机会模型。
- 增加草稿模型。
- 增加线索模型。
- 增加触达记录和审计日志模型。
- 保留现有任务、内容、评论、AI 报告模型作为底层数据来源。

### Phase 4: 官方 API 发送链路

- 定义 `PlatformProvider` 抽象。
- 实现官方 API 权限检测。
- 实现发送前敏感词检查。
- 实现用户确认后的评论发送。
- 实现用户确认后的私信发送。
- 实现限频、额度消耗和失败处理。
- 实现发送审计日志。

### Phase 5: 真实联调与风控保护

- 接入第一个真实官方 API Provider。
- 校验 token 过期、权限不足、限频失败、发送失败等错误路径。
- 增加前端错误提示和禁用态。
- 增加测试覆盖。
